# Beginner Example Assets

This folder shows one complete beginner-track shape:

- [`agents/`](agents/) — seven role-scoped custom agents with an explicit handoff chain.
- [`prompts/`](prompts/) — seven numbered prompts, one per workflow step.
- [`skills/azure-naming-and-tagging/SKILL.md`](skills/azure-naming-and-tagging/SKILL.md) — reusable CAF naming, tagging and no-secrets guidance.
- [`handovers/pipeline-handover-log.md`](handovers/pipeline-handover-log.md) — the written artifact that keeps context between agents.

The examples intentionally use placeholders such as `<environment>` and `<region>` instead of live environment values.
